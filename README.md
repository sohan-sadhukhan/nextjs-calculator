# 🧮 Next.js Calculator App

A modern calculator app built with **Next.js 15**, **React 19**, and **shadcn/ui**, offering both basic and advanced arithmetic operations with a clean, responsive UI powered by **Tailwind CSS**.

## ✨ Features

- 🔢 Two calculators: **Basic** and **Advanced**
- 🎛️ Operator selection with icons using `lucide-react`
- 🎨 Styled with `tailwindcss` and `shadcn/ui` components
- 🌗 Theme support via `next-themes`
- ⚡ Fast development with Turbopack

## 🛠️ Tech Stack

- 🧠 **Next.js 15** – React framework
- ⚛️ **React 19** – UI library
- 🎨 **shadcn/ui** – Component styling
- 💨 **Tailwind CSS 4** – Utility-first CSS
- 🖼️ **Lucide React** – Icon set
- 🛡️ **TypeScript** – Type safety

## 🧮 Components

### 🔵 Basic Calculator

- Four operations: Add, Subtract, Multiply, Divide
- Simple layout with four buttons
- Total displayed in a disabled input field
- Reset button clears all fields

### 🔴 Advanced Calculator

- Operator selection via dropdown with icons
- Input fields for two numbers
- Total displayed after calculation
- Reset button clears all fields


## 🚀 Getting Started

To run this project locally,  follow these steps:

### 1. Install Dependencies
Install all required packages using your preferred package manager:
```bash
# With npm
npm install

# With yarn
yarn install

# With pnpm
pnpm install
```
### 2. Start the Development Server
Once dependencies are installed, launch the local server using one of the following commands:
```bash
# With npm
npm run dev

# With yarn
yarn dev

# With pnpm
pnpm dev
```
